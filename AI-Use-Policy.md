# CMP 131 – Artificial Intelligence Use Policy

AI tools, including GitHub Copilot and ChatGPT, may be used as learning assistants in this course. They must support your learning rather than replace your own thinking and programming.

## Permitted Uses

You may use an AI tool to explain a Python concept in simpler language, explain interpreter errors and error messages, provide a small hint or guiding question, help identify a problem in code you have already written, suggest test cases, review a plan, explain course material, or help improve comments, formatting, or variable names.

## Prohibited Uses

You may not use an AI tool to generate a complete solution, write or replace an entire program or function, submit AI-generated code you cannot explain, copy code without understanding it, use AI during a quiz or examination unless explicitly permitted, or misrepresent AI-generated work as entirely your own.

## Student Responsibilities

You are responsible for every line of code you submit. You must be able to explain what the program does, how its main sections work, why you selected particular variables, functions, loops, or conditions, and how you tested and corrected the program.

The instructor may ask you to explain or modify your code. If you cannot explain submitted code, the work may not receive credit.

## Required AI-Use Report

If you use GitHub Copilot, ChatGPT, or another AI tool, complete `AI-Use-Report.md`. If you did not use AI, indicate that in the report.

## Academic Integrity

AI assistance must follow the course academic-integrity policy. When uncertain whether a particular use is allowed, ask the instructor before using the AI tool.
